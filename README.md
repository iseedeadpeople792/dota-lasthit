# Помощник добивания крипов (Dota 2)

Показывает над полоской здоровья крипа, сколько ударов нужно до добивания, и подсвечивает полоску зелёным, когда добить можно одним ударом. Только смотрит на картинку игры: не читает память, не внедряется в процесс, ничего не нажимает за игрока.

## Запуск
`run.bat` (или из приложения Dota2Stats: ⚙ → «Запустить»). Dota 2 должна быть в оконном режиме или «окно без рамки» и быть активным окном. В полноэкранном (эксклюзивном) режиме оверлей показать нельзя.

## Как работает
1. Захват окна игры (Windows Graphics Capture) → `lasthit/capture.py`.
2. Поиск полосок здоровья по форме (рамка + ровная заливка) → `detect.py`.
3. Урон героя читается с панели (встроенный OCR Windows), разброс урона — из базы героев → `engine.py`, `heroes.py`.
4. Отслеживание полосок между кадрами и плавное сопровождение → `track.py`.
5. Прозрачное окно поверх игры → `overlay.py`.

Вспомогательное: `draft.py` (герои по верхней панели), `settings.py` (допущения про крипов), `status.py` (статус для приложения), `cli.py`.

## Допущения
Полоска показывает только долю здоровья, а ближний и дальний крип выглядят одинаково, поэтому число ударов считается для обоих типов (550 HP/броня 2 и 300 HP/броня 0 по умолчанию, меняется в настройках) и показывается диапазоном; зелёным — только когда добивание гарантировано для обоих.

## Обновление данных
`update_heroes.py` — база героев и иконки (после патчей).

## Проверки
`.venv\Scripts\python.exe -m pytest`
